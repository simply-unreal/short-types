# Short Types


**Short Types** is a lightweight, easy-to-use, header-only C library that provides shorter, cleaner names for common primitive data types.

It brings a more modern naming style to C, similar to languages like Rust, while keeping the simplicity and performance of standard C types.

## Features

- Header-only no build step required
- Zero runtime overhead
- Uses standard C fixed-width types
- Portable across platforms
- Cleaner and shorter type names

## Usage

copy and paste short_types.h into your project director
and include it like this
```c
#include "short_types.h"
```
then read the examples in src/main.c
